Callback

Get the callback.

Callback is an iPhone app that prepares you for iOS developer interviews. It works entirely offline — no account, no network, no analytics.

What's inside

  • Six core topics: Swift, Memory, Concurrency, SwiftUI, UIKit, and Behavioral.
  • Short lessons with syntax-highlighted code, each ending in a quick check.
  • Timed mock interviews with a pause-safe timer.
  • A review queue that resurfaces what you got wrong or flagged.
  • A readiness score that weights recent answers and topic coverage.
